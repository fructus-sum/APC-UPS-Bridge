POWER PROTECTION

Devices & power rules

Remote SSH shutdown and optional Wake-on-LAN recovery. Disabled by default; actions require an observed online-to-battery transition.

Loading…

Safety first

Configuring these rules can shut down remote computers. Test key-based SSH, host-key verification and permission to run shutdown -h now before enabling automation. Use sudo -n only for specifically authorized non-root accounts. No SSH passwords or arbitrary commands are accepted.

Only hosts explicitly approved below are affected. Every action is recorded before execution. Failed/ambiguous commands are not automatically retried. A reboot cannot repeat an attempted action.

Global protection rules

Remote devices

Priorities run in ascending order. Devices must be enabled individually for shutdown and Wake-on-LAN. The Wake address must be a valid IPv4 broadcast address for your network.

Access and security

This software listens on the address chosen when launching the process. The default is 127.0.0.1:8080. Access beyond the host requires explicit opt-in; use HTTPS or a trusted VPN for remote administration.

Remote shutdown and Wake-on-LAN are available on the dedicated Power rules page. They remain disabled until explicitly approved. Automatic shutdown of the local Raspberry Pi is not included in Phase 4.
